# action-test

Example and test repository for the [Lokal PII Scan](https://github.com/marketplace/actions/lokal-pii-scan) GitHub Action.

The workflow in `.github/workflows/pii.yml` is the one from the [Lokal README](https://github.com/lokal-id/lokal#lokal-scan-keep-personal-data-out-of-the-repository). Every name, NIK, and phone number in this repository is made up.
